# Campaign Log — Actual Play Record

This file tracks what actually happened at the table, session by session — as distinct
from `journal.qmd` (a blank player-facing template, not a record) and `chapter*.qmd`
(the written script, which is a plan, not a history). When actual play diverges from
the script, **this file is the source of truth going forward**, not the chapter text.

Update this after every real session, before prepping the next one. This file existing
is the fix for what happened on 2026-08-22: a major table-level plot development
(Varro's betrayal, Lucius's takeover) had no written record anywhere, and had to be
reconstructed from memory under time pressure the night before a session.
