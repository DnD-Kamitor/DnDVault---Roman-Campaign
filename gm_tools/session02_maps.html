Loading These Maps in MapTool

  1. Launch MapTool: Maptool/maptool.sh
  2. Open campaign: File > Open Campaign > Maptool/campaigns/5e/RomanCampaign.cmpgn
  3. Import map image: File > Add Resource to Library > Local Directory
  4. Navigate to Maptool/maps/ and select the campaign folder
  5. Drag the JPG from the resource library onto the map canvas
  6. Set grid: Edit > Map Properties > Grid Size = 40px (overview) or 60px (battle)
  7. Place tokens from Maptool/tokens/ on the background layer
  8. Add token light sources via Edit > Campaign Properties > Light Sources

Note: JPG exports are in Maptool/maps/*.jpg — use these for MapTool import. The HTML files are for DM browser preview only (they render in higher quality than the JPG exports).
